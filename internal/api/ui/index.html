Правила

Здесь заводят свои типы персональных данных, убирают их и выбирают, что маскирует каждая система. Правка идёт в тот же файл настроек, из которого работает сервис, и применяется сразу. Встроенные типы удалить нельзя — их выключают снятием галочки у системы.

Хранится только в этой вкладке и пропадает при обновлении страницы.

Кому принадлежат данные

Фрагменты собираются по людям: соседство в предложении, общий якорь анкеты, повтор значения. Через эти связи выражается правило задания «пин-код один не маскируем, пин-код с картой маскируем»: оно о связи между фрагментами, а не о фрагменте.
