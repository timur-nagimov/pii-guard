# Качество: полная картина

Документ описывает, что решение находит, чего не находит и где ставит маску
лишнюю. Все числа сняты прогоном `cmd/score` на наборе из 10 000 размеченных
записей 23.09.2026 и воспроизводятся двумя командами:

```
go run ./cmd/gen   -out corpus/dataset.jsonl -n 8000 -seed 42
go run ./cmd/score -dataset corpus/dataset.jsonl -split
```

Набор пересобирается из генератора при каждом прогоне ворот, а его отпечаток
лежит в `scripts/corpus.sha256` рядом с базовой линией. Это не формальность:
набор однажды отстал от генератора, линия осталась снятой на старом наборе, и
сравнение потеряло смысл, ничем себя не выдав.

## Что означает число

Основная мера — **доля изменённого**: какая часть размеченного фрагмента
оказалась под маской. Единица означает, что фрагмент закрыт целиком; ноль —
что он остался в тексте открытым. Мера намеренно строгая: наполовину
закрытый паспорт защитой не является.

Ложные срабатывания измеряются **отдельной колонкой** и только на
отрицательных категориях — текстах, где персональных данных нет вовсе, но
есть что-то похожее по форме. Смешивать их с долей изменённого нельзя: у
отрицательной категории размеченных фрагментов нет, и доля изменённого равна
нулю по построению, а не по качеству.

Утром 23.09 сумма была 165.6%. Снижение дали семь правок: бесплатные номера
800, 803 и 804 принадлежат организации; голая форма паспорта рядом со словом
«ИНН» паспортом не является; явное название другого документа отменяет
паспорт даже при якоре; ИНН, за которым идёт КПП, принадлежит юридическому
лицу; номер дома в слитной записи это одна-три цифры; фамилия после правовой
формы в кавычках — название фирмы; исторические правители добавлены в словарь
известных людей.

**ИНН организации остаётся замаскированным намеренно.** Набор размечает
десятизначный ИНН и как персональные данные, и как не-персональные в разных
категориях. Между утечкой ИНН человека и лишней маской на ИНН фирмы выбор
сделан в пользу «не утечь».

## Где решение слабее всего

**Место рождения, 0.9265.** Место пишут свободным текстом, и граница значения
размыта: «д. Заречье, Брянская область, Россия» — три части, любая из которых
может оказаться последней. Пропуски сосредоточены на записях, где после
значения идёт служебный хвост без знака препинания.

**Гражданство, 0.9301.** Название страны само по себе персональными данными
не является, поэтому нужен якорь. Пропуски там, где гражданство указано в
таблице без подписи столбца.

**Паспорт, 0.9362.** Остаток — записи, где серия и номер разнесены по разным
строкам таблицы.

**Текст со строчной буквы.** Среднее по типам задания падает с 0.9576 до
0.9273, и почти весь провал даёт один тип: `FIO` 0.9413 → 0.6280. Имя со
строчной буквы неотличимо от обычного слова без словаря, а словарь имён
конечен. Следом идут `BIRTH_PLACE` 0.8498 и `CARDHOLDER` 0.8871.

**Строка выгрузки, 0.6169.** Самый слабый сценарий. В строке через табуляцию
значения стоят голыми, без подписей: `09/09/2018 г. 2898007147 20.4.1961
vasilev1966@gmail.com 575193 OK`. Типы, которым нужен якорь, здесь его не
находят. Сама структура строки — признак, и его решение пока не использует.

## Виды маскирования

Замер на общем наборе, доля изменённого:

| Вид | Значение |
|---|---|
| `token` — плейсхолдер `[PASSPORT_1]` | 0.9959 |
| `initials` — инициалы | 0.9952 |
| `full` — звёздочки | 0.9496 |
| `synthetic` — подстановка правдоподобного значения | 0.9496 |
| `partial` — видны последние знаки | 0.5693 |

Низкое число у `partial` — не дефект, а его устройство: вид намеренно
оставляет часть значения видимой, и мера считает это неполным закрытием. Для
обмена с языковой моделью годятся `token` и `full`; `partial` предназначен для
показа человеку, который уже имеет право видеть данные.

## Что гарантируют ворота

`bash scripts/gate.sh` — семнадцать проверок одной командой. Для качества это
значит:

- ни один срез не проседает больше чем на 0.005 от записанной линии;
- доля ложных в отрицательных категориях не растёт;
- набор пересобирается заново и сверяется по отпечатку: сдвиг линейки
  закрывает ворота с прямым указанием снять линию осознанно;
- персональные данные не попадают в журнал и в показатели;
- скорость горячего пути не проседает больше чем на четверть.

Сами ворота проверяются отдельно: `bash scripts/gate-selfcheck.sh` подсовывает
каждой проверке заведомую поломку и требует, чтобы она покраснела. Одиннадцать
проверок. Это не избыточность: проверка ложных срабатываний однажды сравнивала
величину, нулевую по построению, и не могла сработать никогда.
