# Быстрый старт за минуту

Стенд поднят и отвечает прямо сейчас. Ничего ставить не нужно, достаточно
`curl`. Этот документ про «потрогать руками»; устройство решения целиком
лежит в [SYSTEM-DESIGN.md](SYSTEM-DESIGN.md), оглавление всех документов в
[README](../README.md).

| Что | Адрес |
|---|---|
| Сервис, контракт проверки | `http://84.201.166.35/process` |
| То же по защищённому протоколу, сертификат самоподписанный | `https://84.201.166.35/process` (нужен `curl -k`) |
| Режим прокси к языковой модели | `http://84.201.166.35/v1/chat/completions` |
| Панель показателей | `http://84.201.166.35:3000` |
| Сырые показатели | `http://84.201.166.35/metrics` |
| Живость и готовность | `http://84.201.166.35/healthz`, `/readyz` |

## Три команды

### 1. Маскирование

```bash
curl -s -X POST http://84.201.166.35/process \
  -H 'Content-Type: application/json' \
  -d '{"payload":"Клиент Иванов Иван Иванович, паспорт 4509 123456, тел. +7 (916) 123-45-67","payload_id":"demo-1"}'
```

```json
{"result":"Клиент ********************, паспорт ***********, тел. ******************"}
```

### 2. Обратное преобразование

Тот же адрес и тот же `payload_id`, в теле замаскированный текст. Направление
сервис определяет сам по содержимому, отдельной ручки нет.

```bash
curl -s -X POST http://84.201.166.35/process \
  -H 'Content-Type: application/json' \
  -d '{"payload":"Клиент ********************, паспорт ***********, тел. ******************","payload_id":"demo-1"}'
```

```json
{"result":"Клиент Иванов Иван Иванович, паспорт 4509 123456, тел. +7 (916) 123-45-67"}
```

Восстановление побайтовое. Повтор первой команды вернёт ту же маску, повторы
безопасны.

### 3. Режим прокси к языковой модели

Совместим с интерфейсом OpenAI. Сервис маскирует запрос, отдаёт его модели и
восстанавливает значения в ответе, поэтому модель видит только плейсхолдеры.
Ключ системы лежит в `.env` под именем `KILO_KEY` и в репозиторий не попадает.

```bash
curl -s -X POST http://84.201.166.35/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -H "X-System-Key: $KILO_KEY" \
  -d '{"model":"deepseek-ai/DeepSeek-V4-Flash-0731",
       "messages":[{"role":"user","content":"Повтори дословно: Иванов Иван Иванович, тел. +7 916 123-45-67"}]}'
```

Ответ приходит в обычном формате `chat.completion`, а имя и телефон в нём уже
восстановлены: модель их не получала.

## Проверить контракт целиком

```bash
make verify URL=http://84.201.166.35     # маска, идемпотентность, восстановление, ответ 422 на мусор
make jury-check URL=http://84.201.166.35 # восемь сценариев по критериям оценки
```

## Запустить у себя

Нужен Go 1.26 либо Docker. Данных и секретов в репозитории нет, поэтому перед
запуском заполняется `.env`.

```bash
cp .env.example .env
printf 'PII_STORE_KEY=%s\n' "$(openssl rand -base64 32)" >> .env

docker compose up -d --build   # сервис, Prometheus и Grafana разом
# либо без Docker:
make run                       # сервис на http://127.0.0.1:8080

make verify                    # проверка контракта на локальном адресе
```

Показатели локально: `http://127.0.0.1:8080/metrics`, панель
`http://127.0.0.1:3000`, сбор `http://127.0.0.1:9090`.

## Нагрузочный прогон

Нагрузку гоняем с отдельной машины: если гонять с машины сервиса, замер
покажет борьбу за процессор, а не задержку сервиса.

```bash
# машина генератора стенда, готовый двоичный файл уже лежит там
ssh -i ~/.ssh/id_ed25519 ubuntu@89.169.172.236

# рабочая частота, тексты по 250 байт, одна минута
/tmp/loadgen -url http://10.129.0.22 -payload 250 -rps 1000 -duration 1m -workers 256

# поиск потолка: частота без ограничения
/tmp/loadgen -url http://10.129.0.22 -payload 250 -rps 0 -duration 1m -workers 512
```

Локально то же самое запускается из исходников:

```bash
go run ./cmd/loadgen -url http://127.0.0.1:8080 -payload 250 -rps 1000 -duration 30s
```

Прогон с подсчётом качества, как у проверяющей системы, делает другой
генератор:

```bash
make corpus                                  # набор из 8000 размеченных текстов
make bench URL=http://84.201.166.35          # 1000 запросов в секунду, 5 минут, с оценкой качества
```

Что получилось на стенде: 999.98 запроса в секунду, доля 99 задержки 0.97 мс,
ни одного отказа, потолок 23 200 запроса в секунду на текстах 250 байт.
